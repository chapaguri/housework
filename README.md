# 집안일 3주 사이클

부부 2인용 집안일 체크리스트. 3주를 한 사이클로 돌리고, 이행/미이행을 집계해 용돈을 정산한다.

**앱**: https://chapaguri.github.io/housework/
**규칙**: [RULES.md](RULES.md) — 체크 · 정산 · 항목 관리 규칙

## 구성

```
index.html            앱 전체 (단일 파일, 의존성 없음)
apps-script/Code.gs   구글 시트를 저장소로 쓰는 동기화 API
RULES.md              체크 · 정산 · 항목 관리 규칙
```

두 사람이 각자 폰에서 체크하면 구글 시트를 거쳐 서로에게 반영된다.
브라우저 저장(localStorage)에 먼저 쓰고 시트로 올리는 방식이라, 오프라인에서도 동작하고
연결되면 대기분이 자동 전송된다.

```
폰 A ─┐
      ├─→ GitHub Pages (index.html) ─→ Apps Script ─→ 구글 시트 '앱데이터' 탭
폰 B ─┘         화면                    동기화 API         저장소
```

## 동작

- 3주(21일) 사이클. 시작일은 앱에서 지정하며 요일에 관계없다
- 선택한 날짜에 해당하는 항목만 보여준다 (매일 / 주말 / 화·목·일)
- 동그라미를 누르면 `완료 → 미이행 → 취소` 순으로 바뀐다
- 지난 날짜인데 체크가 없으면 미이행으로 집계된다
- 여행 등으로 집을 비운 날은 `제외` 버튼으로 집계에서 뺀다. 주간 횟수 목표도 비례 축소된다
- 매달 항목은 3주차에만 나타난다. 미완료가 남아 있으면 3주차 탭에 점이 표시된다
- 주차별 담당자를 입력할 수 있다

## 저장 형식

시트의 `앱데이터` 탭에 key/value 한 벌로 쌓인다. 항목 단위로 병합되므로
두 사람이 동시에 눌러도 서로의 기록을 덮어쓰지 않는다.

| 키 | 뜻 |
|---|---|
| `d\|2026-08-13\|k1` | 실행 (`1` 완료, `2` 미이행) |
| `c\|2026-08-13\|k1` | 확인 (상대방) |
| `x\|2026-08-16` | 제외일 |
| `m\|2026-08\|m3` | 매달 항목 실행 |
| `cm\|2026-08\|m3` | 매달 항목 확인 |
| `o\|2026-08-13` | 담당자 (주 첫날 날짜) |
| `lk\|2026-08-13` | 주차 정산 마감 |
| `cyc\|2026-08-13` | 사이클 등록 |

체크리스트 **항목 정의**는 같은 시트의 `항목` 탭에서 읽어온다. 탭이 없거나 형식이
맞지 않으면 `index.html` 에 내장된 기본 목록으로 폴백한다. 열 구성과 편집 규칙은
[RULES.md](RULES.md) 참고.

## 동기화 API 설치

`apps-script/Code.gs` 파일 상단 주석에 설치 순서가 있다. 요약하면:

1. 데이터를 저장할 구글 시트를 만들고 ID를 `SHEET_ID` 에 넣는다
2. Apps Script 편집기에 코드를 붙여넣고 저장
3. `readAll` 함수를 한 번 실행해 권한을 승인한다 — **이 단계를 빼면 "앱 권한 없음"이 난다**
   그리고 `seedTasks` 를 한 번 실행하면 `항목` 탭이 현재 항목으로 채워진다
4. 배포 → 웹 앱 / 실행: 나 / 액세스: **모든 사용자**
5. 나온 `/exec` URL을 `index.html` 의 `DEFAULT_SYNC` 에 넣는다

### 걸려 넘어지기 쉬운 것

- **회사 Google Workspace 계정은 액세스 `모든 사용자` 옵션이 차단**돼 있을 수 있다. 그러면 개인 계정으로 만들어야 한다
- 스크립트는 시트에 붙어 있지 않은 **독립(standalone) 프로젝트**다. 시트의 `확장 프로그램 → Apps Script` 로는 열리지 않고 빈 프로젝트가 새로 생긴다. <https://script.google.com/home> 에서 직접 열 것
- 재배포할 때 버전을 `새 버전` 으로 골라야 한다. 기존 버전을 고르면 옛 코드가 계속 돌아간다. `VERSION` 상수로 어느 코드가 살아있는지 확인할 수 있다
- 독립(standalone) 스크립트에서는 `getActiveSpreadsheet()` 가 `null` 이다. 그래서 `openById(SHEET_ID)` 를 쓴다
- 읽기와 쓰기 모두 GET 이다. POST 응답은 리다이렉트 뒤 본문을 읽지 못하는 경우가 있어, 쓰기는 되지만 결과를 못 받아 같은 요청을 무한 재전송하게 된다
- `file://` 로 열면 CORS 때문에 동기화가 안 된다. 로컬 확인은 `python3 -m http.server` 로 한다
